# Vidya Solar Energy Dashboard ☀️

A web-based dashboard to monitor and visualize solar energy production at **Vidya Academy of Science & Technology, Thrissur**.

🌐 **Live Dashboard:** https://aruncx.github.io/solarvidya/

## About

The Vidya Solar Energy Dashboard presents solar production data from the college's three solar installations in a clear, interactive interface. It helps users explore energy generation over daily, monthly, yearly, and all-time periods.

## Key Features

- 📊 Interactive production charts and summary cards
- 🏫 Separate production views for the Auditorium, South Block, and Administration Block
- ➕ Combined campus production overview
- 📅 Tab-based daily, monthly, and yearly data exploration
- 🌱 Estimated environmental benefits, such as avoided CO₂ emissions, where configured
- 📱 Responsive design for desktop, tablet, and mobile devices
- 📄 Historical production views powered by the connected Google Sheets data source

## Data and Updates

Production figures are retrieved from the configured Google Sheets / Google Apps Script backend. The dashboard reflects the readings available in that source; missing or unverified readings may affect summaries and charts.
